## 🚨 Fake News Detection using Machine Learning

A Machine Learning project that detects whether a news article is **Real** or **Fake** using **Natural Language Processing (NLP)** techniques and a **Linear Support Vector Classifier (LinearSVC)** model.

### 🔍 Project Overview

This project analyzes news article text, cleans and preprocesses the data, applies TF-IDF vectorization, and trains a machine learning model to classify news articles accurately.

### ⚙️ Features

* Data preprocessing and cleaning
* Stopword removal and lemmatization
* TF-IDF feature extraction
* WordCloud visualizations
* Fake vs Real news classification
* Model evaluation using accuracy, confusion matrix, and classification report
